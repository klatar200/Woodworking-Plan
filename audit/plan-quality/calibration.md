## Questions for Keagan

**Q1 — R9 (pocket-hole jig setting) decides most verdicts. Keep it at Fix?**
R9 fails in 35 of 70 plans, and is the *only* failure in at least 16 Fix plans: Kreg plans usually
name the screw length ("1 1/4″ pocket hole screws") but not the jig thickness setting. Scored as
written, about half the catalog becomes Fix for this one line.
- **Recommended:** keep recording R9, but report it once as a catalog-wide item (one bulk fix: state
  the setting per part thickness) and do not count it toward a plan's Fix/Unpublish verdict.
- Alternatives: keep R9 as a per-plan Fix (as written), or drop R9.
- Sub-point: one reader found the setting only in step images ("1″ thickness" on the drawing). If
  R9 stays, a setting shown in a viewed image counts as stated (recommended).

**Q2 — Real problems no check catches. Add a check?**
Readers recorded 33 plans with `gaps`: problems in sense or measurement that R-1 has no check for, so
they don't affect the verdict. Examples: doors built but never hung (hinges never used); bench seats
glued up but never installed; "cut 11 slats" vs a cut list of 12; 13 slats with 3 1/2″ gaps that need
87 1/2″ in an 80″ opening; shelf or cord-hole positions given nowhere; brackets, staples or wall
anchors used but not in materials. `classic-craftsman-style-queen-bed` is Ship only because its
rail-count mismatch is a gap.
- **Recommended (R-2):** add **R14 "steps, cut list and materials agree"**: counts and sizes match,
  every part made is installed, and every item used is listed. Fix level; Unpublish when the plan
  stops before the build is complete. Also widen **R10** to "every position the builder must set is
  given (a number, or a viewed image showing it)", not only positions the text implies. Then re-score
  the 70 read plans before Stage 6.
- Alternative: leave R-1 as is, and list gaps in the report without changing verdicts.

**Q3 — R1 has no Fix level.** When only a non-structural piece is in the missing PDF (the
`mantel-clock-with-free-printable-dial` dial, `mega-lego-table` cutout shapes), the plan can still be
built. Today that is `unknown`/`likely` and goes to Human review.
- **Recommended:** R1 at **Fix** when the build can be completed without the missing content;
  Unpublish only when it can't (as now).

**Q4 — Cost of Stage 6.** Reading cost about 23–27k tokens per plan (images included). The remaining
540 plans at that rate is about 13–14M tokens, close to this session's whole budget, and many hours.
- **Recommended:** run the Stage 6 readers on Sonnet (cheaper and faster), and keep every Unpublish
  finding with a fresh Opus verifier as now. Re-check a 10-plan sample against Opus readers first.
- Alternatives: all Opus (as piloted); or read only the ~440 plans the sweep flagged and give the 170
  unflagged plans a lighter pass.

## Notes on how the rubric was applied (for the record)

- R5 is `unknown` in 45 of 70 plans because the plan uses several stock types and the steps don't
  name the stock for each part (R-1's precondition). That is most of "Ship (unverified)". No change
  proposed.
- R4/R5 apply §9 nominal sizes; a part Kreg wrote as `2" x 4"` is compared as a 2x4 (sweep rule 1).
- Deviations from the brief: images are cached in the gitignored `audit/plan-quality/.img-cache/`,
  not the scratchpad (the project's guard blocks writes outside the repo); readers opened unflagged
  images only to show that something exists nowhere in a plan (R1/R11); one reader ran a read-only
  `git check-ignore`. No plan or catalog file was changed.
